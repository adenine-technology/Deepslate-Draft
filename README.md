# Deepslate Draft

A mobile-first web app for viewing, following and (eventually) generating Minecraft Bedrock Edition schematics, layer by layer.

> **Status: in development.** Features below are marked as built or planned. Update the checkboxes as the app grows.

## What it does

- View a build one layer at a time, with a final 3D preview
- See real block textures from your own resource pack, so you know exactly what to place in-game
- Block counts per layer and for the whole build
- Installable on your phone like an app (PWA), and works offline
- Everything runs in your browser. Nothing is uploaded anywhere

## Features

### Viewer
- [ ] Layer viewer on canvas with Previous / Next Layer
- [ ] Jump-to-layer slider, swipe, pinch zoom and pan
- [ ] Block Count (current layer and total)
- [ ] Final View (isometric preview)
- [ ] Chunk grid overlay and coordinate readout

### Textures
- [ ] Import your own Bedrock resource pack (`.zip` / `.mcpack`)
- [ ] Original generated tiles when no pack is imported
- [ ] Block state overlays (facing, powered, waterlogged, repeater delay)

### Build-along tools
- [ ] Mark layers and blocks as placed, with progress tracking
- [ ] Materials list in stacks and shulker boxes
- [ ] Saved builds library with JSON backup and restore

### Planned later
- [ ] Load Bedrock structure files
- [ ] Editing and shape tools
- [ ] Generate builds from text instructions
- [ ] Redstone contraptions and farms (designs are unverified until tested in-game)

## Use it

**Live site:** `https://[USERNAME].github.io/deepslate-draft/`

### Install on your phone

**iPhone (Safari):** open the site, tap the Share button, then **Add to Home Screen**.

**Android (Chrome):** open the site, tap the three-dot menu, then **Install app** or **Add to Home screen**.

### Add textures

Deepslate Draft does not include Minecraft's textures. To see real blocks:

1. Get a Bedrock resource pack onto your device (for example, one you already use in the game, or any pack you have the right to use).
2. In the app, open **Settings > Import resource pack** and choose the file.
3. The textures are stored on your device only. You can remove them at any time from the same screen.

Until a pack is imported, the app shows its own pixel tiles.

## Run or host your own copy

No build step is needed.

1. Fork or download this repository.
2. In your repository on GitHub, go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and the `/ (root)` folder, then save.
4. After a minute or two, your site appears at `https://[USERNAME].github.io/deepslate-draft/`.

To test locally, serve the folder with any static server (service workers need `http://localhost` or HTTPS, not a plain file open), for example:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

### Updating

Upload the changed files to the repository. The app shows an "update available" prompt the next time it is opened online. If an old version seems stuck, close the app fully and reopen it.

## Privacy and security

- All data (builds, settings, imported textures) stays in your browser's storage. Nothing is sent to a server.
- Imported files are validated for size and type before use.
- The app uses a strict Content Security Policy and loads no third-party scripts.
- Browsers can clear stored data, especially on iPhone. Use the built-in **Export backup** regularly.

Found a security problem? Please open a private security advisory on this repository rather than a public issue.

## Known limitations

- Redstone and farm designs generated by the app have not been tested in-game unless stated. Always test before relying on them.
- Targets Bedrock Edition behaviour only, which differs from Java Edition in redstone and some block states.
